核心亮点与功能

把云端订阅软件的常用体验，完整带回你的本地设备

🔒

免登录 · 无水印 · 全本地

无需注册或联网验证，所有素材与渲染均在本地完成，保障隐私安全，导出视频零水印限制。

🎞️

完整多轨时间轴

支持视频与音频多轨编辑、精准剪辑分割、丰富转场与视觉特效，满足日常到进阶的剪辑需求。

🗣️

本地 AI 自动字幕与配音

内置离线 AI 语音识别自动生成字幕，并支持文字转语音（TTS）以及声音克隆功能。

🪄

智能背景移除与人声隔离

无需绿幕即可一键抠除视频背景，配合人声分离工具，轻松处理口播与混音素材。

⚡

最高 4K 60FPS 高清导出

支持 H.264、HEVC 与 AV1 等主流编码格式，最高可导出 4K 分辨率、60 帧高画质成片。

🦀

高性能底层架构

基于 Rust 等现代技术构建，启动迅速、资源占用可控，充分发挥本地硬件解码与渲染性能。

面向脚本与 AI Agent 的自动化剪辑

Concat 内置 JSON-RPC API 与 MCP（Model Context Protocol） 支持。开发者或创作者可以直接通过外部脚本或 AI Agent 编程控制时间轴、自动粗剪与批量出片。

协议采用 AGPL-3.0 开源许可，社区活跃，适合二次开发与工作流集成。
